ATIVIDADE 1 — MONGODB
ETAPA 4 — EXECUTANDO CONSULTAS COM OPERADORES

1. Listar todos os restaurantes com pontuação (score) maior que 30

db.restaurants.find({ "grades.score": { $gt: 30 } })


2. Listar todos os restaurantes com pontuação (score) menor que 10

db.restaurants.find({ "grades.score": { $lt: 10 } })


3. Listar todos os restaurantes com culinária (cuisine) italiana ("Italian") E com CEP "10075"

db.restaurants.find({
    cuisine: "Italian",
    "address.zipcode": "10075"
})


4. Listar todos os restaurantes com culinária (cuisine) italiana ("Italian") OU com CEP "10075"

db.restaurants.find({
    $or: [
        { cuisine: "Italian" },
        { "address.zipcode": "10075" }
    ]
})
