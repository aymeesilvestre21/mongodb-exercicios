# Exercício 03 — Georeferenciamento com MongoDB e GeoJSON

Este diretório contém a resolução do Exercício 03 de MongoDB.

## Objetivo

Desenvolver uma solução em Python para coletar, tratar e armazenar dados georreferenciados em formato GeoJSON no MongoDB.

## Tecnologias utilizadas

- Python
- Requests
- Pandas
- GeoPandas
- PyMongo
- MongoDB

## Dados utilizados

Dados georreferenciados de Unidades Básicas de Saúde (UBS).

- `georef_data_collector.py`
- `requirements.txt`
- `.env.example`
- `.gitignore`
