# Prática 04 — OpenF1 Data Explorer

Este diretório contém a resolução da Prática 04 de MongoDB.

## Objetivo

Criar uma aplicação web com Streamlit para consultar e visualizar os dados da Fórmula 1 já armazenados no MongoDB.

## Funcionalidades

- Seleção de ano
- Seleção de sessão de corrida
- Visualização de informações da sessão
- Seleção de múltiplos pilotos
- Comparação de tempos de volta
- Gráfico de desempenho por volta
- Visualização dos dados em tabela

## Arquivos da resolução

- `streamlit_app.py`
- `db_utils.py`
- `requirements.txt`
- `.env.example`
- `.gitignore`
